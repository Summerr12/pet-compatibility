# pet-compatibility

I am in early stages of development

Choosing a pet is usually riddled with a lot of unknowns whether its if the potential owner is unsure if they have the full capacity for a pet or if they aren't sure of what is really out there. This project is meant to help people make more informed decisions and increase visibility for animals and adoption.

## Planned features

- Realistic overview: showing what caring for a given pet means such as space and time commitment
- Quiz on defining how good of a owner you can be
- Awareness encouraging animal knowledge

## Data sources
- RescueGroups.org API
